## 公开规则

- 未真实执行的 rerun 不写成已完成结果。
- rerun 结果若波动较大，应公开波动范围，而不是只挑最好一次。
- rerun 与主运行必须使用相同数据规模、依赖版本、采集脚本和统计脚本。
- 如果 rerun 结论弱于主运行，应降级公开口径，例如写成“主运行显示明显收益，重复运行仍需补充”。
